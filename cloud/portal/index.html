在另一台电脑使用

  1. 在那台电脑运行看板程序，填写自己的项目和任务。
  2. 运行同步程序的“连接”命令，浏览器会打开此网站的配对页。
  3. 用自己的账号登录，选择自己的项目，再确认连接。
  4. 保持同步程序运行，网站就会收到持续更新。

登录账号之间的数据独立。其他人不能看到你的项目，也不需要你的 Cloudflare 部署账号。

同步上传进度摘要和任务记录，不读取完整聊天内容；本地代码的变动需要由负责窗口更新任务记录后，才会反映到进度。
